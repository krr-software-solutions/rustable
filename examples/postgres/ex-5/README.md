# ex-5 — snip.ly (URL shortener), 1 migration

The service launched with its entire schema in a single file: an enum, two tables, indexes,
a plpgsql function, a trigger and comments.

Features exercised: big multi-statement file, `/* */` block comment header, `CREATE TYPE … AS ENUM`,
`GENERATED ALWAYS AS IDENTITY` and `GENERATED BY DEFAULT AS IDENTITY`, `varchar(16)` with regex
`CHECK`, named table-level `CHECK`, FK `ON DELETE CASCADE`, descending composite index, partial index,
plpgsql function with a **named dollar-quote tag** (`$fn$ … $fn$`), `AFTER INSERT` trigger,
`COMMENT ON TABLE/COLUMN`.
